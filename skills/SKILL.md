# AI Chat Skills

Put skill files here — one folder per skill. Each skill folder contains a
SKILL.md file (plus any helper assets). Skills can be attached to a
conversation from the "+" menu in the chat input; their content is injected
into the agent's system prompt for that conversation.

Example skill layout:

    skills/my-skill/
        SKILL.md          # skill instructions (Markdown)
        assets/...        # optional helper files

Create a skill by making a folder here with a SKILL.md inside.
